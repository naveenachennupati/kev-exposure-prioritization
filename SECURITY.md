# Security policy for public demonstration code

This project contains only code and safe example/replay data. **Do not open a public issue with access tokens, company security logs, nonpublic asset inventories, scanner exports, customer identifiers, or credentials.**

For a security issue, contact the repository owner privately after publication. Project examples are not a production managed security service, and there are no customer service commitments.

## Security engineering safeguards

- No credential collection, account disablement, asset remediation or production security-rule activation in examples.
- Use only systems and data you own or are explicitly authorized to assess.
- Check input source completeness and record provenance; do not claim third-party operational outcomes.
- GitHub Actions use repository read-only permissions and upload only safe example report artifacts.
